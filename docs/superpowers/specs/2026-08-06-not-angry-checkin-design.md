# 不生气打卡小程序 — 设计文档

**日期：** 2026-08-06
**状态：** 已确认（V1 已实现；V2 增强设计已确认）

## 1. 概述

一款微信小程序，帮助用户培养"不生气"的习惯。

- **早上**：用户开启当日挑战，承诺今天不生气。
- **晚上**：用户确认今天确实没有生气，当日挑战成功。
- **统计**：连续未生气天数、累计天数、最多连续天数。
- **成就**：连续打卡达到 3 / 7 / 14 / 30 / 100 天时解锁里程碑徽章。
- **V2 增强**：情绪管理（生气即时记录 + 深呼吸安抚）、数据可视化（月度日历 / 趋势图 / 原因词频）、内容激励（每日一句 + 里程碑鼓励）、成就扩展（满勤 / 行为 / 衍生成就）。

## 2. 约束与决策

| 项目 | 决策 |
|------|------|
| 平台 | 微信小程序（原生 WXML/WXSS/JS） |
| 存储 | 本地存储 `wx.setStorageSync`，单用户 |
| 提醒 | 无定时推送（不引入订阅消息） |
| 打卡流程 | 早设定 + 晚确认，二者都完成才计入成功 |
| 技术栈 | 原生微信小程序，无第三方依赖 |
| V2 可视化 | 图表用 `<canvas>` 手绘，不引入图表库 |
| V2 句库 | 内置本地句库，不联网 |

## 3. 页面结构

### 3.1 pages/checkin（今日打卡，Tab 1）

- 顶部：当前日期 + 当日状态文案。
- 主状态区：
  - 未设定：按钮【开启今日挑战】。
  - 已设定未确认：提示"已承诺，期待今晚好消息"。
  - 已确认：完成动效 + "今日挑战成功"。
- 底部：当前连续天数大数字展示。

### 3.2 pages/stats（统计与成就，Tab 2）

- 统计卡：连续天数 / 累计天数 / 最多连续天数。
- 成就徽章网格：3 / 7 / 14 / 30 / 100 天。已解锁为彩色，未解锁为灰色锁定。

### 3.3 pages/calm（深呼吸安抚页，V2 新增，非 Tab）

- 从打卡页"今天忍不住生气了"记录后进入。
- 3 轮"吸气 4 秒 → 屏息 4 秒 → 呼气 6 秒"环形动画引导。
- 一句安慰语；完成后可返回打卡页。

## 4. 数据存储

storage key：`checkin_records`

```
[
  { "date": "2026-08-06", "done": true, "started": true, "angry": false, "reason": [] },
  { "date": "2026-08-05", "done": true }
]
```

- `date` 为 `YYYY-MM-DD` 字符串。
- `started` 为 true 表示当天开启过挑战。
- `done` 为 true 表示当日挑战成功。
- `angry` 为 true 表示当天生气过（当天挑战失败，不计入连续/累计）。
- `reason`：生气原因数组，元素为预置标签或自定义文本。
- `unlocked_achievements`：已解锁成就 ID 数组（V2 起改为存储成就 ID 而非数字）。

> V2 决策：记录结构升级，`angry`/`reason` 为可选字段，旧数据（仅 `done`）仍兼容。成就存储从"里程碑数值"改为"成就 ID"，首次运行自动迁移。

## 5. 核心逻辑

### 5.1 当日状态推导（utils/date.js + utils/store.js）

给定今天日期 `today`，状态机四态：

- `done === true` → **done（挑战成功）**
- `angry === true` → **angry（今天生气了）**
- `started === true` → **pending（已承诺未确认）**
- 否则 → **idle（未设定）**

### 5.2 天数统计（utils/store.js `computeStats`）

对 `checkin_records` 按日期升序排序去重：

- **累计天数**：`done === true` 的记录条数。
- **连续天数**：从今天（或昨天）往回数连续 `done === true` 的天数。
  - 若今天已 `done`，从今天开始计数；否则从昨天开始计数（今天还没确认，昨天若成功则连续天数延续）。
  - 若昨天也不成功，则连续天数为 0（今天未确认）或 1（今天已确认）。
- **最多连续天数**：遍历历史，计算过的最长连续成功段。

### 5.3 情绪记录（V2 新增）

- `store.recordAngry(reasons)`：把今天记录设为 `{ started:true, angry:true, done:false, reason:[...] }`，当天连续中断。
- `store.getReasonFrequency()`：统计所有记录 `reason` 中标签/自定义词出现次数，返回降序数组。

### 5.4 成就判定（V2 扩展，utils/achievements.js）

成就分三类，均存成就 ID：

| 类型 | 成就 ID | 判定条件 |
|------|---------|---------|
| 连续里程碑 | `streak_3/7/14/30/100/365` | 当前/最佳连续天数达到 |
| 满勤 | `month_full` | 单个自然月内每天都有 done（月末校验） |
| 满勤 | `week_full_2` / `week_full_4` | 连续 2 / 4 个完整自然周内每天 done |
| 行为 | `angry_log_5` / `angry_log_20` | 累计生气记录 5 / 20 次 |
| 行为 | `start_7` | 连续 7 天开启过挑战 |
| 行为 | `recover_3` | 生气后 3 天内重新连续 3 天 |
| 衍生 | `best_7` / `best_30` | 最佳连续天数 ≥ 7 / 30（自动推导，无需新行为） |

判定时机：`checkin` 页每次打卡/记录生气后统一调用 `achievements.checkAndUnlock()`，全量扫描；新增解锁弹提示。已解锁 ID 不重复弹。

### 5.5 内容激励（V2 新增）

- `utils/quotes.js`：内置 30+ 句正能量句库，`getDailyQuote(date)` 按日期确定性选取（同一天恒定）。
- `utils/encourage.js`：`getDoneMessage(streak)` / `getCalmMessage()`，按连续天数分档鼓励文案。

## 6. 页面数据流

- `app.js`：全局无状态，仅做生命周期。
- `pages/checkin`：`onShow` 刷新状态机 + 连续天数 + 每日一句；【开启今日挑战】→ `startToday`；【今晚确认】→ `confirmToday` + `checkAndUnlock`；【今天忍不住生气了】→ 弹层选原因 → `recordAngry` → 跳转 `pages/calm`。
- `pages/calm`：进入自动开始 3 轮呼吸动画，结束显示安慰语 + 返回。
- `pages/stats`：`onShow` 刷新统计卡 + 成就徽章 + 月度日历 + 近 30 天趋势图 + 原因词频。

## 7. 错误处理与边界

- storage 读取失败或数据损坏（非数组）时，视为空数据并重置。
- 同一日期重复确认：幂等，不重复计数。
- 重复记录生气：幂等，不重复叠加原因；重复触发成就检查不重复弹提示。
- 跨天切换：页面 `onShow` 每次重新计算，天然按自然日切分。
- 日期计算使用本地时区，避免 UTC 偏移导致跨天错误。
- 旧版本数据（无 `angry`/`reason`）兼容读取；`unlocked_achievements` 旧数值自动迁移为 `streak_N` ID。

## 8. 测试

由于是微信小程序，无自动化测试框架。自动化部分用 Node 冒烟测试（mock `wx` 与 `Date`），其余为手动测试清单：

1. 首次进入 → idle 状态，连续天数 0。
2. 开启今日挑战 → pending 状态。
3. 今晚确认 → 连续 1，累计 1。
4. 次日确认 → 连续 2。
5. 隔一天不确认 → 连续归零，累计保留。
6. 连续达 3/7 天 → 成就解锁并弹提示；再次达到不重复弹。
7. 记录生气 → 当天 angry 状态、连续中断、进入安抚页、`angry_log_5` 计次。
8. 月度日历/趋势图/词频随数据刷新。
